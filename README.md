# SpeedyJob 功能改进方案

## 一、选择改进的功能

**JD 匹配分析 + 简历优化建议（一站式整合）**

基于 SpeedyJob（https://www.speedyjob.cn/）现有的「简历优化」「简历打分」「JD匹配」等独立功能，提出一站式整合改进。

## 二、当前问题

SpeedyJob 目前提供了多个求职工具（简历生成、简历打分、简历优化等），但存在以下问题：

1. **功能割裂**：JD 匹配分析和简历优化建议是分离的两个入口，用户需要多次操作才能完成「分析差距 → 获得建议 → 改进简历」的完整流程。
2. **缺少针对性**：简历优化建议是通用型的，没有基于特定 JD 给出定向建议，导致优化方向不够精准。
3. **反馈不够直观**：缺少多维度可视化评分（技能/经验/教育/关键词等维度拆解），用户无法快速定位短板。

## 三、改进方案

### 核心思路：一站式 JD-简历匹配诊断 + 定向优化

将匹配分析与优化建议合入同一工作流，用户粘贴「简历 + 目标 JD」后一键获得：

| 模块 | 输出内容 |
|------|---------|
| 匹配总分 | 0-100 综合评分 + 匹配等级 |
| 多维度拆解 | 技能匹配 / 经验匹配 / 教育匹配 / 关键词覆盖 / 行业相关度 |
| 关键词对比 | 已匹配关键词（绿色） vs 缺失关键词（红色） |
| 技能差距分析 | 按重要性排序的缺失技能 + 补充建议 |
| 定向优化建议 | 按优先级排序，含具体改写示例 |
| 优化简历预览 | 自动生成补充建议的简历版本 |

### 技术实现

- **后端**：Spring Boot 3 + HanLP 中文分词 + 自定义技术词典 + 多维度评分算法
- **前端**：纯 HTML/CSS/JS 单页应用，分数环动画 + 维度进度条 + 标签化关键词
- **架构特点**：本地 NLP 分析（无需外部 API），也预留了 AI 接口扩展能力

## 四、设计理由

1. **用户价值最大化**：求职者最核心的需求是「知道差距在哪 + 怎么改」。一站式流程将分析和建议合一，减少操作步骤，提升转化效率。
2. **可量化反馈**：多维度评分让用户清楚每个维度的差距大小，知道优先改什么。
3. **可操作性强**：每条建议附带具体示例（原文 → 改写），而不是笼统的方向性建议。
4. **技术可行性**：使用 HanLP + 自定义词典实现关键词提取，无需依赖外部 AI API 即可运行，降低部署门槛。

## 五、Vibe Coding 过程说明

整个项目完全使用 AI 编程助手（GitHub Copilot）协作完成，过程如下：

| 阶段 | AI 协作方式 |
|------|-----------|
| **需求调研** | AI 爬取 SpeedyJob 官网，分析现有功能列表和描述，识别改进机会 |
| **方案设计** | 向 AI 描述痛点，由 AI 提出一站式整合方案，确认多维度评分维度划分 |
| **架构设计** | AI 设计 Spring Boot 项目结构：Model → Service → Controller 分层 |
| **代码生成** | AI 逐文件生成全部代码，包括关键词提取引擎、匹配评分算法、优化建议生成器、前端页面 |
| **调试优化** | AI 检查代码一致性，处理编译错误，优化评分权重参数 |
| **文档编写** | 本文档由 AI 根据实现过程自动生成 |

**关键决策均由人类确认**：功能选择、评分维度权重、优化建议优先级规则等核心设计决策由人与 AI 讨论后做出。

## 六、运行方式

```bash
cd jd-resume-matcher
mvn spring-boot:run
# 访问 http://localhost:8080
```

**说明**：本 MVP 使用本地 NLP（HanLP 分词 + 自定义技术词典）实现匹配分析，无需调用外部 AI API。如需更智能的语义分析，可配置 OpenAI API Key 扩展。
